# Spreadsheet Prophet

> Turn your boring CSV into a tarot reading with confidence intervals.

An AI tool that reads a user's CSV and produces a three-card forecast: past, present, and possible future. It maps columns to archetypes, summarizes anomalies, and flags which metric is most likely to betray you.

## Features
- Upload a CSV and infer column types, units, and anomalies
- Generate a three-card narrative with plain-language insights
- Plot a forecast band for one selected numeric column
- Export a PDF or image suitable for sharing

## Stack
- FastAPI
- Python
- Pandas
- Streamlit

## Getting started
```
pip install -r requirements.txt && streamlit run app.py
```
